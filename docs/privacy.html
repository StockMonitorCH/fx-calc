FX Calc – Datenschutzerklärung

Deutsch / English below

Datenerhebung

FX Calc erhebt und speichert keine persönlichen Daten. Die App erfordert keine Registrierung und kein Benutzerkonto.

Netzwerkzugriff

Die App ruft live Wechselkurse und Rohstoffpreise von Yahoo Finance ab (api.finance.yahoo.com). Dabei werden nur die angefragten Währungspaare übertragen – keine Nutzeridentifikation.

Optional prüft die App auf neue Versionen über die GitHub Releases API (api.github.com). Auch dabei werden keine persönlichen Daten übertragen.

Lokale Speicherung

Die App speichert ausschliesslich, ob du die Datenschutzerklärung bestätigt hast (SharedPreferences, lokal auf deinem Gerät).

Drittanbieter

  • Yahoo Finance – Kursdaten (keine personenbezogenen Daten)
  • GitHub – Update-Prüfung (keine personenbezogenen Daten)

Kontakt

Bei Fragen: www.stock-monitor.ch

FX Calc – Privacy Policy

Deutsch oben / English

Data Collection

FX Calc does not collect or store personal data. No registration or user account is required.

Network Access

The app fetches live exchange rates and commodity prices from Yahoo Finance (api.finance.yahoo.com). Only the requested currency pairs are transmitted – no user identification.

Optionally, the app checks for new versions via the GitHub Releases API (api.github.com). No personal data is transmitted in this process.

Local Storage

The app only stores whether you have confirmed the privacy policy (SharedPreferences, stored locally on your device).

Third Parties

  • Yahoo Finance – Exchange rate data (no personal data)
  • GitHub – Version check (no personal data)

Contact

For questions: www.stock-monitor.ch
