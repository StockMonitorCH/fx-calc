FX Calc – Datenschutzerklärung

Deutsch / English / 中文

Entwickler: Boner Timm Peter Emanuel (Stock Monitor) | www.stock-monitor.ch

Datenerhebung

FX Calc erhebt und speichert keine persönlichen Daten. Die App erfordert keine Registrierung und kein Benutzerkonto.

Netzwerkzugriff

Die App ruft live Wechselkurse und Rohstoffpreise von Yahoo Finance (api.finance.yahoo.com) ab. Dabei werden nur die angefragten Währungspaare übertragen – keine Nutzeridentifikation.

Optional prüft die App auf neue Versionen über die GitHub Releases API (api.github.com). Auch dabei werden keine persönlichen Daten übertragen.

Lokale Speicherung

Die App speichert ausschliesslich Benutzereinstellungen (z.B. bestätigte Datenschutzerklärung, Eingabefelder im Zinsrechner) lokal auf dem Gerät (SharedPreferences). Es werden keine Daten an externe Server übertragen.

Drittanbieter

  • Yahoo Finance – Kursdaten (keine personenbezogenen Daten)
  • GitHub – Update-Prüfung (keine personenbezogenen Daten)

FX Calc – Privacy Policy

Deutsch / English / 中文

Developer: Boner Timm Peter Emanuel (Stock Monitor) | www.stock-monitor.ch

Data Collection

FX Calc does not collect or store personal data. No registration or user account is required.

Network Access

The app fetches live exchange rates and commodity prices from Yahoo Finance (api.finance.yahoo.com). Only the requested currency pairs are transmitted – no user identification.

Optionally, the app checks for new versions via the GitHub Releases API (api.github.com). No personal data is transmitted in this process.

Local Storage

The app only stores user preferences locally on the device (e.g. confirmed privacy policy, savings calculator inputs) via SharedPreferences. No data is sent to external servers.

Third Parties

  • Yahoo Finance – Exchange rate data (no personal data)
  • GitHub – Version check (no personal data)

FX Calc – 隐私政策

Deutsch / English / 中文

开发者：Boner Timm Peter Emanuel（Stock Monitor）| www.stock-monitor.ch

数据收集

FX Calc 不收集或存储任何个人数据。本应用无需注册或创建用户账户。

网络访问

本应用从 Yahoo Finance（api.finance.yahoo.com）实时获取汇率和大宗商品价格。仅传输所请求的货币对信息，不涉及任何用户身份识别。

本应用可选择通过 GitHub Releases API（api.github.com）检查新版本。此过程中不传输任何个人数据。

本地存储

本应用仅在设备本地存储用户偏好设置（例如：已确认隐私政策、利率计算器输入内容），使用 SharedPreferences 实现。不向外部服务器发送任何数据。

第三方服务

  • Yahoo Finance – 汇率数据（不涉及个人数据）
  • GitHub – 版本检查（不涉及个人数据）
